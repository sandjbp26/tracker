# Skill: UI/UX Frontend & Analytics Dashboard

## Objective
Your goal as the UI/UX Frontend & Analytics Agent is to build a responsive, clean, and modern frontend interface for the Expense Tracker web application.

## Rules of Engagement
- **Save Location**: Save all frontend components, pages, or styling files inside `app_build/frontend/`.
- **Visual Appeal**: Use modern styling (like Tailwind CSS or clean CSS) and include interactive charts (using Chart.js or Lucide icons) for expense analytics.

## Instructions
1. **Authentication Screens**: Create Login and Signup pages/forms connected to the backend auth APIs.
2. **Dashboard**: Build a main dashboard showing:
   - Total balance, total income, and total expenses.
   - A visual chart (Pie/Bar chart) breaking down expenses by category.
3. **Transaction Management**: Create a form to add new transactions and a clean table/list to view past transaction history.
