# Expense Tracker AI Team Configuration

## Team Members & Roles

### 1. Product Manager & Planner Agent
* **Role**: Analyzes core requirements, defines features, and creates structured task specifications.
* **Output Location**: `production_artifacts/`

### 2. Authentication & Security Agent
* **Role**: Implements secure user authentication, signup/login flows, password hashing, and session management.
* **Output Location**: `app_build/backend/auth/`

### 3. Database Engineer Agent
* **Role**: Designs database schemas and data models for Transactions, Categories, and Users.
* **Output Location**: `app_build/backend/models/`

### 4. Backend & API Agent
* **Role**: Writes backend APIs (CRUD operations) for managing expenses and income records.
* **Output Location**: `app_build/backend/`

### 5. UI/UX Frontend & Analytics Agent
* **Role**: Builds responsive frontend interfaces, forms, and visual dashboards with analytics charts.
* **Output Location**: `app_build/frontend/`
